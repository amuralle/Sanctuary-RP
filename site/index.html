In-game field guide

Collection placement commands

These commands are available to every player. Enter them in normal chat with an exclamation point, not as slash commands.

Command reference

!volunteer help
Shows the collection volunteer commands in game.
!volunteer pools
Lists the exact pool keys available in your current zone.
!volunteer place [pool] [optional note]
Saves your position, height, and facing. A linked collectible node appears immediately so you can inspect the placement.
!volunteer mine [page]
Lists your submissions eight at a time, including each submission ID and review status.
!volunteer undo [#id|last]
Removes one of your pending submissions and its linked live node. Use last to undo your newest placement.

Placement workflow

  1. Move to the exact spot where the center of the collection node should sit.
  2. Confirm the ground is reachable and the node will not be hidden inside terrain or scenery.
  3. Run !volunteer pools and choose the appropriate pool for that region.
  4. Place the node with an optional landmark note, then inspect and collect it in game.
  5. Use !volunteer undo last immediately if the height, position, or pool is wrong.
  6. Refresh this page and select the pool to verify the new marker on the regional map.

In-game reference

Roleplay commands

Miniature and collection survey commands are available to every player. Commands marked admin only are DM presentation tools. Miniature short IDs reset when the zone or server restarts.

Scene workflow

  1. Search here or run !mini models [term] to find a model ID.
  2. Place related pieces in a named group such as @guards or @props.
  3. Use !mini list @group to find short IDs for speech, inspection, and removal.
  4. Walk to a destination and use !mini move #id here, then add speech or a supported emote.
  5. Clean up with !mini clear @group when the scene ends.
