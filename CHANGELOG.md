# Change history

This file records reviewed public updates to Sanctuary-RP. Dates describe source
publication, not necessarily production deployment. See the
[commit history](https://github.com/amuralle/Sanctuary-RP/commits/main/) for the
complete source history and [the publishing guide](docs/RELEASING.md) for releases.

## 2026-11-14 - Project identity, community, and website source

- Replaced the inherited upstream README with an OSFR-RP overview covering the
  roleplay purpose, miniatures, DM tools, community surveys, branch differences,
  setup, limitations, and upstream credits.
- Added the Free Realms Roleplay Community Hub Discord invite and a verified
  working toolkit URL: `https://play.osfr-rp.com/guide/`.
- Added a website source guide covering static preview, backend dependencies,
  public contribution data, authentication boundaries, and publishing practices.
- Added this change history, a publishing guide, and a security policy with private
  GitHub vulnerability reporting enabled.
- Added website navigation to the Discord community, source repository, project
  documentation, and update history.
- Updated the contribution guide and RP issue templates, corrected the license
  badge, and clarified the repository description and topics.

These changes document existing RP capabilities and improve project navigation.
They do not introduce a new game-server feature, a database migration, or a tagged
binary release. Unfinished local gameplay and map work is outside this publication.
